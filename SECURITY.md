# Security

Wimap reads a lot about the PC it runs on, so security reports are taken seriously.

If you find a way for Wimap to read or export something it shouldn't (a token, a password, a private file), or for a map file to run code or reach the network, please don't open a public issue. Report it privately through GitHub's **Report a vulnerability** button on the Security tab of this repository.

Please include the Wimap version (Help › About Wimap), your Windows version, and the steps to reproduce. You'll get a reply within a week.
